# Docker

Containers and container-based deployment.

- **[Docker: Get Started](https://docs.docker.com/get-started/)** — official, always-current getting-started guide covering images, containers, and Compose.
- **[Docker Docs](https://docs.docker.com/)** — the full official reference manual (CLI, Dockerfile, Compose, networking, storage, security) you return to afterward.
- **[Docker 101 Tutorial](https://www.docker.com/101-tutorial/)** — official interactive beginner walkthrough.
- **[Docker Curriculum](https://docker-curriculum.com/)** — community tutorial that goes further, building and deploying a real app end-to-end.
- **[Play with Docker](https://labs.play-with-docker.com/)** — free, no-signup browser sandbox that can link multiple real nodes into an actual Swarm cluster.
- **[DevOps with Docker (University of Helsinki)](https://courses.mooc.fi/org/uh-cs/courses/devops-with-docker-spring-2026)** — free, deeper university course covering multi-container apps, Compose, and CI integration — a rigorous tier above the shorter community tutorial above.
