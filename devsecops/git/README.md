# Git

Version control fundamentals and workflows.

- **[Atlassian Git Tutorials](https://www.atlassian.com/git/tutorials)** — comprehensive, free series covering git fundamentals, branching, merging, rebasing, and team workflows.
- **[Pro Git](https://git-scm.com/book/en/v2)** — the official, free, authoritative git book; the deep reference once you're past the basics.
- **[Learn Git Branching](https://learngitbranching.js.org/)** — interactive visual sandbox for practicing branching and merging in the browser.
- **[Oh Shit, Git!?!](https://ohshitgit.com/)** — cheat sheet for recovering from common git disasters (undoing commits, detached HEAD, lost work).
