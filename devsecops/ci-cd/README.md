# CI/CD

Continuous integration and deployment pipelines.

- **[GitHub Actions Docs](https://docs.github.com/en/actions)** — official documentation for building CI/CD workflows on GitHub, the platform most attendees will touch first.
- **[GitLab CI/CD Docs](https://docs.gitlab.com/ci/)** — official documentation for building and securing CI/CD pipelines in GitLab.
- **[CICD-Goat](https://github.com/cider-security-research/cicd-goat)** — deliberately vulnerable CI/CD environment (Jenkins, GitLab CI, Argo CD) for hands-on pipeline-security practice.
