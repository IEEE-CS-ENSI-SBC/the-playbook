# Terraform

Infrastructure as Code.

- **[Terraform Tutorials](https://developer.hashicorp.com/terraform/tutorials)** — official HashiCorp tutorials, the standard entry point for Infrastructure as Code.
- **[Terraform Best Practices](https://www.terraform-best-practices.com/)** — community guide on code organization, module structure, naming, and state management.
- **[TerraGoat](https://github.com/bridgecrewio/terragoat)** — deliberately insecure Terraform templates for practicing IaC misconfiguration detection; the attack/defend counterpart here, same role as CICD-Goat and Kubernetes-Goat.
