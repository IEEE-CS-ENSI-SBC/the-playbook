# Secure Coding

Writing and checking code for security, independent of any one tool pillar.

- **[Semgrep Academy: Secure Coding](https://academy.semgrep.dev/courses/secure-coding)** — free course covering core vulnerability classes (injection, XSS, etc.) and secure coding principles, with hands-on labs.
- **[LFD121: Developing Secure Software](https://training.linuxfoundation.org/training/developing-secure-software-lfd121/)** — free Linux Foundation/OpenSSF course covering the whole secure SDLC (requirements, design, implementation, testing), broader than vulnerability-class labs.
- **[Snyk Learn](https://learn.snyk.io/catalog/)** — appsec training catalog covering dependency/supply-chain scanning and container/IaC security.
- **[ShellCheck](https://www.shellcheck.net/)** — static analysis tool that catches bugs and unsafe patterns (quoting, injection-prone constructs) in shell scripts before they hit a pipeline.
- **[OWASP (official channel)](https://www.youtube.com/@OWASPGLOBAL)** — talks and content from the Open Web Application Security Project, covering the OWASP Top 10 and secure coding practices.
- **[The Fuzzing Book](https://www.fuzzingbook.org/)** — free, comprehensive academic book on fuzzing and automated test-input generation for finding bugs.
