# Kubernetes

Container orchestration.

- **[Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/)** — official interactive tutorial covering pods, deployments, and services.
- **[Kubernetes Docs](https://kubernetes.io/docs/home/)** — the full official reference manual (concepts, tasks, API reference) you keep coming back to.
- **[kubectl Quick Reference](https://kubernetes.io/docs/reference/kubectl/quick-reference/)** — official condensed cheat sheet of common `kubectl` commands.
- **[Introduction to Kubernetes (LFS158x)](https://training.linuxfoundation.org/training/introduction-to-kubernetes/)** — free Linux Foundation course (video + labs) covering architecture, networking, and security in more depth.
- **[Helm Docs](https://helm.sh/docs/)** — the standard package manager for Kubernetes: charts, templating, and release management.
- **[Play with K8s](https://labs.play-with-k8s.com/)** — free, no-signup browser sandbox for building an actual multi-node Kubernetes cluster from scratch.
- **[DevOps with Kubernetes (University of Helsinki)](https://courses.mooc.fi/org/uh-cs/courses/devops-with-kubernetes-2026)** — free university course, project-based: build and deploy real applications throughout, from the team behind Full Stack Open.
- **[Kubernetes the Hard Way](https://github.com/kelseyhightower/kubernetes-the-hard-way)** — manually bootstraps a cluster component by component, teaching the internals instead of just using `kubectl`.
- **[Kubernetes Goat](https://github.com/madhuakula/kubernetes-goat)** — deliberately vulnerable Kubernetes cluster for practicing security misconfigurations (RBAC, container escapes), the attack/defend counterpart to everything else here.
- **Hacking Kubernetes** — Andrew Martin, Michael Hausenblas — O'Reilly book on Kubernetes threat modeling and security.
