# Reading

Foundational books and methodology behind the practices in this category.

- **[The Twelve-Factor App](https://12factor.net/)** — classic, highly influential methodology for building deployable, scalable cloud-native apps; the principles underneath the tools elsewhere in this category.
- **[DORA](https://dora.dev/)** — research-backed framework for DevOps performance metrics (deployment frequency, lead time, change failure rate) and capabilities.
- **[The Phoenix Project (excerpt)](http://images.itrevolution.com/documents/The_Phoenix_Project_excerpt.pdf)** — free preview of the canonical DevOps novel that popularized much of this thinking.
- **[Continuous Delivery (official preview)](https://api.pageplace.de/preview/DT0400.9781492056676_A49444847/preview-9781492056676_A49444847.pdf)** — official sample chapters of Humble & Farley's classic book on build/test/deployment automation.
- **The DevOps Handbook** — Gene Kim, Jez Humble, Patrick Debois, John Willis — classic book on building agility, reliability, and security into technology organizations.
- **Threat Modeling: Designing for Security** — Adam Shostack — the standard reference on threat modeling methodology.
