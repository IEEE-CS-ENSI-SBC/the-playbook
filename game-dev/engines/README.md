## Resources

- **[Brackeys](https://www.youtube.com/@Brackeys)** — legendary, beloved channel of beginner-friendly tutorials spanning both Unity and Godot.
- **[Making Games with Python & Pygame](https://inventwithpython.com/pygame/)** — free beginner-friendly book for Pygame, the simplest code-only starting point.
- **[Phaser Tutorials](https://phaser.io/tutorials)** — official tutorials for the web/JS 2D game framework.
- **[LÖVE (Love2D): Getting Started](https://love2d.org/wiki/Getting_Started)** — free, lightweight Lua-based 2D game framework, popular for simple indie games.
- **[Defold: Learn](https://defold.com/learn/)** — free, lightweight cross-platform 2D engine (Lua-based), used by some commercial studios.
- **[raylib Examples](https://www.raylib.com/examples.html)** — simple, popular C library for learning low-level game programming fundamentals.
- **[MonoGame: Getting Started](https://docs.monogame.net/articles/getting_started/index.html)** — free C#/.NET game framework, spiritual successor to XNA.
- **[Bevy: Learn](https://bevyengine.org/learn/)** — free, open-source, Rust-based game engine with a modern ECS architecture.
- **[Unofficial Bevy Cheat Book](https://bevy-cheatbook.github.io/)** — well-known community reference/cheat sheet for Bevy, complementing the official docs.
- **[Hands-on Rust](https://pragprog.com/titles/hwrust/hands-on-rust/)** — book structured entirely around building a complete roguelike in Rust; game-dev-specific despite teaching the language along the way.
- **[RogueLike Tutorials](https://rogueliketutorials.com/)** — free tutorial series for building a roguelike game, pairs well with the 7DRL jam.
- **[Box2D Documentation](https://box2d.org/documentation/)** — official docs for the extremely popular open-source 2D physics engine, used as the physics backend in many other engines.
