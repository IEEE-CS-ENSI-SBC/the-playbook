# Graphics Programming

Learning raw graphics APIs directly, rather than through an engine.

- **[LearnOpenGL](https://learnopengl.com/)** — the classic, extremely well-regarded resource teaching native OpenGL graphics programming (C++) from scratch.
- **[WebGL2 Fundamentals](https://webgl2fundamentals.org/)** — classic resource teaching the underlying WebGL graphics API itself.
- **[Three.js Journey](https://threejs-journey.com/)** — extremely well-regarded course for Three.js, the JS 3D graphics library built on WebGL.
- **[Vulkan Tutorial](https://vulkan-tutorial.com/)** — tutorial for the modern, lower-level Vulkan graphics API.
- **[vkguide](https://vkguide.dev/)** — a more modern, practical Vulkan tutorial focused on building an actual renderer.
- **[LearnWebGPU](https://eliemichel.github.io/LearnWebGPU/)** — tutorial for WebGPU, the modern successor to WebGL.
