# Unity

- **[Unity Learn](https://learn.unity.com/)** — official learning platform for Unity, the industry-standard commercial engine.
- **[Code Monkey](https://www.youtube.com/@CodeMonkeyUnity)** — popular, prolific channel of practical Unity implementation tutorials.
- **[Catlike Coding: Unity Tutorials](https://catlikecoding.com/unity/tutorials/)** — highly-regarded advanced Unity tutorials (shaders, procedural meshes, rendering), a step up from Unity Learn's official beginner content.
