# Design

Game mechanics, balance, and design theory — not programming or graphics.

- **[Game Design Concepts](https://gamedesignconcepts.wordpress.com/)** — Ian Schreiber's free course on game design fundamentals.
- **[Game Balance Concepts](https://gamebalanceconcepts.wordpress.com/)** — same author, focused specifically on game balance and economy design.
- **[Level Design Book](https://book.leveldesignbook.com/)** — free book specifically on level design.
- **[Game Maker's Toolkit (GMTK)](https://www.youtube.com/@GMTK)** — excellent, widely-respected channel analyzing game design decisions in real games.
- **[A Theory of Fun for Game Design](https://www.theoryoffun.com/)** — Raph Koster's legendary book on what makes games fun.
- **[The Art of Game Design: A Book of Lenses](https://www.artofgamedesign.com/)** — Jesse Schell's legendary book, the "100 lenses" approach to game design.
