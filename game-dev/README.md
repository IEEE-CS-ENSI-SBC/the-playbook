# Game Dev

Game engines, game design, game programming, and game art/audio/tooling.

## Sub-categories

- [No-Code Tools](no-code/README.md) — make a game without writing code
- [Engines & Frameworks](engines/README.md) — real game programming, visual editors to code-only libraries
- [Foundations](foundations/README.md) — theory, math, and graphics concepts underneath game programming
- [Art](art/README.md) — drawing, painting, and 3D art fundamentals
- [Audio](audio/README.md) — sound design and music implementation
- [Design](design/README.md) — game mechanics, balance, and design theory
- [Game Jams](jams/README.md) — build a game under a time limit
- [Networking](networking/README.md) — multiplayer architecture and implementation
- [Publishing & Business](publishing/README.md) — marketing, distribution, business

## Resources

- **[GameDev.tv](https://www.gamedev.tv/)** — well-regarded, broad game dev education platform spanning Unity, Unreal, Godot, game design, and art — not tied to one engine.
- **[CS50's Introduction to Game Development](https://cs50.harvard.edu/games/)** — Harvard's free, structured course teaching 2D game design principles by rebuilding classic games.
- **[GDC Vault](https://www.gdcvault.com/)** — Game Developers Conference talks archive, spanning design, programming, art, and audio — not tied to one subcategory.
