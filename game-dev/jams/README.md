# Game Jams

Build a game under a time limit — great for practicing finishing something small.

- **[Ludum Dare](https://ldjam.com/)** — the most famous, longest-running game jam.
- **[itch.io Jams](https://itch.io/jams)** — hub listing hundreds of ongoing and upcoming game jams across itch.io.
- **[Global Game Jam](https://globalgamejam.org/)** — the largest worldwide annual game jam, often run in-person at local sites.
- **[Godot Wild Jams](https://godotwildjams.com/)** — recurring game jam specifically for the Godot engine community.
- **[JS13K Games](https://js13kgames.com/)** — game jam for making a game in JavaScript under a strict 13KB size limit.
- **[7-Day Roguelike Challenge](https://7drl.com/)** — annual jam specifically for building a roguelike game in 7 days.
