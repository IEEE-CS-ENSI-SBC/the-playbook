# Art

Drawing, painting, and 3D art fundamentals for game assets.

- **[Draw a Box](https://drawabox.com/)** — free, extremely popular structured drawing fundamentals course (perspective, form, construction).
- **[Ctrl+Paint](https://www.ctrlpaint.com/)** — free digital painting fundamentals course.
- **[Blender Studio Training](https://studio.blender.org/training/)** — official training for Blender, the free 3D modeling/animation tool widely used for game assets.
- **[CG Cookie](https://cgcookie.com/)** — well-regarded community platform for Blender/3D art tutorials (modeling, animation, texturing).
- **[Lospec: Pixel Art Tutorials](https://lospec.com/pixel-art-tutorials)** — well-known hub for pixel art tutorials and palettes, the standard style for many indie games.
- **[Slynyrd: Pixel-Blog Catalogue](https://www.slynyrd.com/pixelblog-catalogue)** — widely-referenced pixel art tutorial series.
- **[Saint11: Pixel Art Tutorials](https://saint11.art/blog/pixel-art-tutorials/)** — another widely-referenced, well-regarded pixel art tutorial collection.
