# Networking

Multiplayer game architecture: client prediction, server reconciliation, lag compensation.

- **[Gaffer On Games](https://gafferongames.com/)** — legendary resource on game networking (reliable UDP, physics networking).
- **[Fast-Paced Multiplayer (Gabriel Gambetta)](https://www.gabrielgambetta.com/client-server-game-architecture.html)** — well-known series on client-server architecture, client prediction, and lag compensation.
- **[Valve: Source Multiplayer Networking](https://developer.valvesoftware.com/wiki/Source_Multiplayer_Networking)** — classic official explanation of Source engine's networking model, widely referenced beyond Source itself.
- **[Godot: High-Level Multiplayer](https://docs.godotengine.org/en/stable/tutorials/networking/high_level_multiplayer.html)** — official Godot-specific guide for implementing multiplayer.
- **[Colyseus Docs](https://docs.colyseus.io/)** — official docs for Colyseus, a popular Node.js-based multiplayer game server framework.
- **[Mirror Networking](https://mirror-networking.gitbook.io/)** — official docs for Mirror, a popular free Unity multiplayer networking library.
- **[GGPO](https://www.ggpo.net/)** — famous rollback netcode library, especially used in fighting games.
