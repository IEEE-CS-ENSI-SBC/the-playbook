# Engine Architecture

How game engines themselves are built.

- **[Game Programming Patterns](https://gameprogrammingpatterns.com/)** — free, legendary book on software design patterns specifically for game code (game loop, component pattern, state machines).
- **[Game Engine Architecture](https://www.gameenginebook.com/)** — the legendary, comprehensive, industry-standard textbook on building game engines.
- **[Handmade Hero](https://handmadehero.org/)** — Casey Muratori's legendary series building a complete game and engine from scratch in C, livestreamed.
- **[Game Engine Black Book (Fabien Sanglard)](https://fabiensanglard.net/gebb/)** — legendary deep technical breakdowns of classic game engines (Wolfenstein 3D, DOOM).
- **[Data-Oriented Design](https://www.dataorienteddesign.com/dodbook/)** — free book on a performance-focused design paradigm heavily used in game engine architecture.
