# Math & Simulation

The math and physics underneath game programming.

- **[3Blue1Brown: Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)** — legendary, beautifully visual series on the linear algebra behind 3D transformations and graphics.
- **[Immersive Math](https://immersivemath.com/)** — interactive linear algebra textbook, complementing 3Blue1Brown's visual intuition with hands-on practice.
- **[The Nature of Code](https://natureofcode.com/)** — free book on simulating physics, particle systems, and behaviors used throughout game programming.
- **[Allen Chou: Game Physics Series](https://allenchou.net/game-physics-series/)** — well-regarded deep-dive series on implementing game physics engines (collision detection, resolution, integration).
