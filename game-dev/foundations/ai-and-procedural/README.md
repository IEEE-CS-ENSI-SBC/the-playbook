# AI & Procedural Generation

NPC behavior, pathfinding, and generating content algorithmically.

- **[Red Blob Games](https://www.redblobgames.com/)** — excellent interactive visual explanations of game-dev algorithms (hex grids, pathfinding/A*, procedural generation).
- **[Sebastian Lague](https://www.youtube.com/@SebastianLague)** — legendary channel on procedural generation, pathfinding, and algorithmic techniques applied in Unity.
- **[Game AI Pro](http://www.gameaipro.com/)** — free collection of professional-level articles on game AI techniques (pathfinding, behavior trees, NPC decision-making).
- **[Procedural Content Generation in Games](http://pcgbook.com/)** — free academic book on procedural generation techniques for games.
