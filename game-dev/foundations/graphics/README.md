# Graphics

Rendering theory and building renderers from scratch — engine- and API-agnostic.

- **[GAMES101](https://sites.cs.ucsb.edu/~lingqi/teaching/games101.html)** — extremely popular, free, comprehensive computer graphics course.
- **[MIT 6.837: Computer Graphics](https://ocw.mit.edu/courses/6-837-computer-graphics-fall-2012/)** — official MIT OpenCourseWare computer graphics course.
- **[Scratchapixel](https://www.scratchapixel.com/)** — one of the most comprehensive free computer graphics resources, covering rendering, geometry, and shading broadly.
- **[Computer Graphics from Scratch](https://gabrielgambetta.com/computer-graphics-from-scratch/)** — free book teaching both raytracing and rasterization from first principles.
- **[Ray Tracing in One Weekend](https://raytracing.github.io/)** — famous free book series building a ray tracer from scratch.
- **[TinyRenderer](https://github.com/ssloy/tinyrenderer/wiki)** — famous "build your own 3D software renderer from scratch" tutorial.
- **[Lode's Computer Graphics Tutorial](https://lodev.org/cgtutor/)** — classic free resource on raycasting and 2D graphics techniques (Wolfenstein-style engines).
- **[javidx9 (One Lone Coder)](https://www.youtube.com/@javidx9)** — builds games, renderers, and graphics demos from scratch in C++, including his own pixel game engine.
- **[Inigo Quilez: Articles](https://iquilezles.org/articles/)** — legendary graphics programmer's articles on advanced shader techniques and signed distance fields.
- **[Freya Holmér (acegikmo)](https://www.youtube.com/@acegikmo)** — legendary deep-dives on game math, splines, and shaders.
