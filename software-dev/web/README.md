# Web

Web development: HTML/CSS/JS fundamentals through full-stack practice.

- **[The Odin Project](https://www.theodinproject.com/)** — free, structured, project-based full-stack web development curriculum.
- **[Eloquent JavaScript](https://eloquentjavascript.net/)** — free, well-regarded book teaching JavaScript from fundamentals through browser/DOM programming.
- **[Frontend Mentor](https://www.frontendmentor.io/)** — real-world front-end challenges: build actual UIs from provided designs.
- **[Flexbox Froggy](https://flexboxfroggy.com/)** — classic, beloved game teaching CSS Flexbox through puzzles.
- **[CSS Battle](https://cssbattle.dev/)** — competitive CSS code-golf challenges: recreate target images with minimal, clever CSS.
