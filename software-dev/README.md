# Software Dev

Application-level programming and design: web, mobile, and desktop apps —
not systems/networking internals (that's `systems`), not CS theory
(that's `computer-science`), and not deployment/security concerns
(that's `devsecops`).

## Sub-categories

- [Web](web/README.md) — web development

## Resources

- **[freeCodeCamp](https://www.youtube.com/@freecodecamp)** — massive, highly-regarded free full-length courses spanning programming fundamentals, web dev, and more.
- **[Boot.dev](https://www.boot.dev/)** — gamified interactive platform teaching backend development fundamentals (Go, Python, APIs, databases).
- **[roadmap.sh: Projects](https://roadmap.sh/projects)** — practical, build-it-yourself application project ideas across backend, frontend, and more.
- **[Fireship](https://www.youtube.com/@Fireship)** — hugely popular, fast-paced channel covering web/app dev, modern tooling, and quick tech explainers.
- **[Tech With Tim](https://www.youtube.com/@TechWithTim)** — popular channel teaching Python and general programming by building real projects and apps.
