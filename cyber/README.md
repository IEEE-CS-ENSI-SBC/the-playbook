# Cyber

Security topics not tied directly to the software development lifecycle:
offensive security/pentesting, CTF, network security, firmware, reverse
engineering, forensics, malware analysis, cryptography.

## Sub-categories

- [CTFs & Practice Platforms](ctfs/README.md) — hands-on practice platforms and wargames
- [Reverse Engineering](reverse-engineering/README.md) — binary analysis, exploit development, OS internals, malware analysis

## Resources

- **[Professor Messer](https://www.professormesser.com/)** — free video courses covering CompTIA fundamentals (A+, Network+, Security+) — networking and security theory foundations.
- **[The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge)** — massive, widely-praised compilation of sysadmin/security tools, CLI tricks, and tips.
- **The Web Application Hacker's Handbook (2nd Edition)** — Dafydd Stuttard, Marcus Pinto — classic, foundational book on finding and exploiting web application security flaws.
- **[John Hammond](https://www.youtube.com/@_JohnHammond)** — broad infosec channel covering CTFs, malware analysis, security scripting, and research.
