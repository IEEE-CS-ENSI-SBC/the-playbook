# Reverse Engineering

Binary analysis, exploit development, OS internals, malware analysis.

- **[OST2 (OpenSecurityTraining2)](https://ost2.fyi/)** — free, university-level courses on reverse engineering, exploit development, and OS internals.
- **[LiveOverflow](https://www.youtube.com/@LiveOverflow)** — one of the best channels for binary exploitation and reverse engineering deep-dives.
- **[pwn.college](https://pwn.college/)** — free, university-affiliated (ASU) hands-on binary exploitation/systems security training from the ground up.
- **[MalwareUnicorn](https://malwareunicorn.org/#/)** — well-known, free, hands-on malware analysis and reverse engineering workshops.
- **[Microcorruption](https://microcorruption.com/)** — classic embedded/firmware reverse engineering wargame (microcontroller exploitation).
