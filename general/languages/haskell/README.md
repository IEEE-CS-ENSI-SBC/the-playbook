# Haskell

- **[Learn You a Haskell for Great Good!](https://learnyouahaskell.github.io/)** — the classic, beloved, free online book; the standard starting point.
- **[CIS 194 (University of Pennsylvania)](https://www.seas.upenn.edu/~cis1940/spring13/)** — free university course materials, a well-regarded next step after the basics.
- **[Haskell.org Documentation](https://www.haskell.org/documentation/)** — official documentation and language reference.
