# C

- **[learn-c.org](https://www.learn-c.org/)** — free, interactive, structured C tutorial; the standard starting point.
- **[Beej's Guide to C Programming](https://beej.us/guide/bgc/)** — classic, beloved, approachable free guide to C.
- **[Modern C](https://modernc.gforth.org/)** — free, comprehensive, more rigorous book covering C including recent standards.
- **[cdecl.org](https://cdecl.org/)** — practical tool that translates between C declarations and plain English; great once pointer/function-pointer syntax gets confusing.
