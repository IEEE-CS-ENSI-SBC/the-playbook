# C++

- **[learncpp.com](https://www.learncpp.com/)** — the most-recommended free, comprehensive, structured C++ tutorial; the standard starting point.
- **[cppreference.com](https://en.cppreference.com/)** — the canonical reference for the C++ standard library and language features; the tool you keep coming back to.
- **[The Cherno](https://www.youtube.com/@TheCherno)** — well-known, in-depth C++ channel covering the language itself (not game-dev specific, despite its popular game engine series).
- **[Compiler Explorer (godbolt.org)](https://godbolt.org/)** — interactive tool showing the assembly your C++ actually compiles to; widely used once you're past the basics.
