# Zig

- **[Zig Language Reference](https://ziglang.org/documentation/master/)** — official documentation; the standard reference.
- **[zig.guide](https://zig.guide/)** — well-known, community-written structured guide, friendlier than the raw reference.
- **[Ziglings](https://ziglings.org/)** — small, official-adjacent exercises for learning Zig by fixing broken code, same spirit as Rustlings.
