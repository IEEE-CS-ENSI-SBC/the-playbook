# Rust

- **[The Rust Book](https://doc.rust-lang.org/book/)** — the official, comprehensive guide to Rust; the standard starting point.
- **[Rustlings](https://github.com/rust-lang/rustlings)** — official small exercises to get comfortable reading and writing Rust syntax.
- **[Rustfinity](https://www.rustfinity.com/)** — broader interactive challenge platform for practicing Rust beyond the basics.
