# General

Cross-field dev tools, references, productivity, and career/soft-skills
— anything not specific to one of the other fields. CS theory and
fundamentals live in `computer-science`.

## Sub-categories

- [Linux](linux/README.md) — the command line, shell scripting, and Linux system administration
- [Languages](languages/README.md) — language-specific learning resources
- [Regex](regex/README.md) — learning and tooling for regular expressions

## Resources

- **[roadmap.sh](https://roadmap.sh/)** — free, community-maintained step-by-step learning roadmaps across frontend, backend, DevOps, cyber security, AI, system design, and more.
- **[The Missing Semester (MIT)](https://missing.csail.mit.edu/)** — free MIT course on the practical skills CS programs usually skip: shell, git, vim, debugging, security basics.
- **[DevHints](https://devhints.io/)** — broad collection of quick-reference cheat sheets across many languages, tools, and frameworks.
- **[DevDocs](https://devdocs.io/)** — fast, searchable, combined browser for official documentation across many languages and frameworks.
- **[free-for-dev](https://github.com/ripienaar/free-for-dev)** — massive, practical list of free tiers of dev/cloud/SaaS tools (hosting, databases, CI/CD, monitoring) for building real projects.
- **[Free Programming Books](https://github.com/EbookFoundation/free-programming-books)** — massive curated list of free programming books, organized by language, across all of CS/software.
- **[Project Based Learning](https://github.com/practical-tutorials/project-based-learning)** — massive, well-curated collection of guided build-along tutorials for real projects across many languages, spanning both applications and systems-level builds.
