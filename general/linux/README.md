# Linux

The command line, shell scripting, and Linux system administration.

- **[linuxcommand.org](https://linuxcommand.org/)** — free, ground-up tutorial on the Linux command line and bash scripting; foundational across nearly every field here.
- **[explainshell.com](https://explainshell.com/)** — breaks down any shell command into its parts with an explanation for each flag.
- **[crontab.guru](https://crontab.guru/)** — interactive tool for building and understanding cron expressions.
- **[LearnLinuxTV](https://www.youtube.com/@LearnLinuxTV)** — well-regarded channel covering Linux system administration, networking, and self-hosting.
- **[OpenVim](https://openvim.com/)** — interactive, browser-based tutorial for learning Vim keybindings and commands.
- **[Vim Adventures](https://vim-adventures.com/)** — a genuinely fun game teaching Vim motions through actual gameplay.
