# Competitive Programming

Algorithmic puzzles and contests: problem-solving under constraints,
leaderboards, and timed challenges.

- **[LeetCode](https://leetcode.com/)** — the essential coding interview/algorithm practice platform.
- **[NeetCode](https://neetcode.io/)** — curated technical interview prep roadmap (the "NeetCode 150" style) with video explanations for each problem.
- **[CSES Problem Set](https://cses.fi/problemset/)** — classic algorithm-topic-organized practice problems (sorting, DP, graphs), a staple of structured CP training.
- **[Codewars](https://www.codewars.com/)** — bite-sized coding challenges ("kata") across many languages, with a kyu/dan ranking system for casual daily practice.
- **[HackerRank](https://www.hackerrank.com/)** — broad platform covering algorithms, SQL, and interview prep; heavily used for recruiting assessments.
- **[AtCoder](https://atcoder.jp/)** — major platform for live, rated competitive programming contests.
- **[Advent of Code](https://adventofcode.com/)** — hugely popular annual series of daily programming puzzles, released every December.
