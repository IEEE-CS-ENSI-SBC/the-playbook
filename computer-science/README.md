# Computer Science

Core CS theory and fundamentals: algorithms, program design, computation,
and the ideas underneath software — distinct from the practical tooling
in `general` and the applied building in `software-dev`.

- **[Teach Yourself CS](https://teachyourselfcs.com/)** — curated CS fundamentals reading/course list (algorithms, systems, databases, networking) for self-taught programmers.
- **[How to Design Programs](https://htdp.org/)** — classic free book teaching program design and functional programming fundamentals (Scheme/Racket), used in intro CS courses.
- **[Structure and Interpretation of Computer Programs](https://sarabander.github.io/sicp/)** — the legendary MIT CS textbook; deeper and more canonical than How to Design Programs.
- **[Computerphile](https://www.youtube.com/@Computerphile)** — well-known, accessible channel covering CS concepts: algorithms, computability, cryptography, computer history, and more.
- **[The Coding Train](https://www.youtube.com/@TheCodingTrain)** — beloved, approachable channel teaching algorithms and programming fundamentals through creative coding (sorting, pathfinding, simulations).
- **[CS50 (Harvard)](https://www.youtube.com/cs50)** — the legendary Introduction to Computer Science course; the most famous intro CS curriculum there is.
- **[Python Tutor](https://pythontutor.com/)** — free tool that visualizes code execution step-by-step (variables, memory, call stack) for Python, Java, C, and JS.
- **[Algorithms (Jeff Erickson)](https://jeffe.cs.illinois.edu/teaching/algorithms/)** — free, highly-regarded university-level algorithms textbook.
- **[Open Data Structures](https://opendatastructures.org/)** — free textbook specifically on data structures, complementing the algorithms textbook above.
- **[Big-O Cheat Sheet](https://www.bigocheatsheet.com/)** — classic quick-reference for time/space complexity of common algorithms and data structures.
- **[Algorithm Visualizer](https://algorithm-visualizer.org/)** — interactive tool animating algorithm execution step-by-step (sorting, graphs, etc.).
- **[VisuAlgo](https://visualgo.net/en)** — another widely-used algorithm/data-structure visualization tool, especially popular for competitive programming.
